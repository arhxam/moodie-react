# Contributing

Thanks for helping Moodie become more expressive without becoming more complicated.

1. Fork the repository and create a focused branch.
2. Install with `npm install`.
3. Add or update tests for behavioral changes.
4. Run `npm run format`, `npm run typecheck`, `npm test`, and `npm run build`.
5. Open a pull request that explains the user-facing result and includes screenshots for visual demo changes.

Expression contributions must use original geometry, retain compatible path topology, work in reduced-motion mode, and include an accessible demo label.
